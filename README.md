# NsuSchedule

> *Educational project built during university.*

A multi-module Android app for viewing NSU class schedules, with class reminders and notifications.

## Tech Stack

* Language: Java/Kotlin
* Platform: Android
* Architecture: Multi-module (app, domain)
* Build System: Gradle

## Structure

- app/ - UI, activities, notifications, and application setup
- domain/ - Core business logic and models
